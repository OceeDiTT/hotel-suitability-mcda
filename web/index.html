Method & parameters

Roads ≥ buffer distance, land cover = agriculture or forest/natural, slope below limit, on a common raster grid; fully suitable cells are vectorised, filtered to ≥ 1 ha and must lie entirely within the urbanisation plan. The weighted-sum raster is informational: every site meets all criteria, so all sites have the same maximum score.
